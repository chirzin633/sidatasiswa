## Key Features

- **Token authentication** with register, login, logout, and current-user endpoints
- **Student records** with NIS, name, class, gender, birth date, and address
- **Soft deletes** so removed students stay recoverable in the database
- **Search** by NIS, name, or class, with sortable columns and pagination (5–50 rows)
- **Dashboard** with student totals, gender counts, class count, class distribution, and recent students
- **Validation and JSON errors** returned consistently by the API and shown in forms
- **API documentation** generated by Scramble

## Installation & Setup

### Backend

1. Install PHP dependencies:

   ```bash
   cd backend
   composer install
   ```

2. Create the environment file and application key:

   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

3. Configure the database in `backend/.env`. The default file uses SQLite; this application needs PostgreSQL:

   ```env
   APP_URL=http://localhost:8000

   DB_CONNECTION=pgsql
   DB_HOST=127.0.0.1
   DB_PORT=5432
   DB_DATABASE=db_siswa
   DB_USERNAME=postgres
   DB_PASSWORD=your-password
   ```

4. Create the database and run migrations:

   ```bash
   psql -U postgres -c "CREATE DATABASE db_siswa;"
   php artisan migrate
   ```

5. Start the API:

   ```bash
   php artisan serve
   ```

   The API runs at `http://localhost:8000/api/v1`. Generated API docs are at `http://localhost:8000/docs/api`.

No user is seeded. Create the first account through the registration form or `POST /api/v1/register`.

### Frontend

1. Install dependencies:

   ```bash
   cd frontend
   npm install
   ```

2. Point the frontend at the API in `frontend/.env`:

   ```env
   VITE_API_BASE_URL=http://localhost:8000/api/v1
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

   Open `http://localhost:5173`.

Run the backend and frontend in separate terminals. For a production build, run `npm run build` in `frontend`.
